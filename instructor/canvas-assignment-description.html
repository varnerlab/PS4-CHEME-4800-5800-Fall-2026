Problem Set 4: Reading a plant logbook

Release: Saturday, October 24, 2026
Initial submission deadline: Saturday, November 7, 2026, at 11:59 PM ET
Maximum score: 4 points

A chemical plant wants 30 years of handwritten logbook readings in a spreadsheet. Teach a computer to read the handwriting one digit at a time. Build a digit reader for 0 through 9 out of ten yes/no models, using the Perceptron and logistic-regression trainers from the Week 9 labs, and check how often it reads whole logbook entries correctly.

Download and instructions

  • Read the complete PS4 instructions
  • Download the PS4 release
  • Read the grading rubric

On the release page, scroll to Assets and select Source code (zip). Extract the archive completely before beginning. This problem set is supported with Julia 1.12.7 and uses the Plots package, which the first command below installs.

What to do

  • Complete the four functions in src/Compute.jl: Part 1 (digit_labels and train_digit_models) and Part 2 (predict_digits and confusion_table).
  • Answer the three questions in responses.md, using the reports the checker writes to the outputs folder.

The starter code is intentionally incomplete, so the tests will fail initially. Do not modify the supplied tests, data, trainers, or submission checker to make an incomplete solution appear to pass.

Check your work

In VS Code, open the extracted assignment folder containing Project.toml, README.md, and check_submission.jl. Open a terminal in that folder and run: 

julia --startup-file=no --project=. -e 'using Pkg; Pkg.instantiate()'
julia --startup-file=no --project=. check_submission.jl

The first command installs the packages; run it once, and expect it to take several minutes. The second runs the submission checker. It runs testme_part_1.jl and testme_part_2.jl, with 24 tests per script and 48 tests total.

The checker always writes MANIFEST.txt and warns if answers are missing or still contain TODO placeholders. After the tests pass, it trains both digit readers (about a minute) and saves the plots and data tables in the outputs folder. Use them to answer the questions.

The checker does not upload anything to Canvas. Written responses are reviewed separately.
